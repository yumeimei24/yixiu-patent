# 可专利性评估维度

> **硬约束**见 `references/regulatory-standards.md`（专利法第 22、25 条及审查指南摘要）。  
> **review 前**须 Read 该文件并按 `prompts/standards_lookup.md` WebSearch 核验。

## 1. 保护客体（《专利法》第2、25条）

**可专利**：对产品、方法或其改进提出的**新的技术方案**。

**通常排除或需谨慎**：

- 科学发现、智力活动规则和方法（纯算法、商业方法无技术载体）
- 疾病诊断和治疗方法（产品/设备/试剂组合等可能可专利，需个案）
- 违反法律、社会公德或妨害公共利益
- 仅呈现自然存在物质（基因片段等规则见审查指南）

**计算机领域**（审查指南第二部分第九章）：须体现**技术问题 + 技术手段 + 技术效果**；纯算法或纯商业规则且无技术特征 → 第 25 条(2)。

## 2. 新颖性（《专利法》第22条）

- 不属于现有技术；不存在抵触申请
- 现有技术：申请日（有优先权则优先权日）前公众可得的技术
- 本 skill 通过 **search** 辅助，不能替代正式检索报告

## 3. 创造性

- 发明：相对最接近现有技术，**突出的实质性特点** + **显著的进步**
- 审查参考：三步法（最接近现有技术 → 区别特征 → 实际技术问题 → 是否显而易见）
- 缺乏对比文件时标记「信息不足」，建议查新

## 4. 实用性

- 能够制造或使用，产生**积极效果**
- 方案是否可实施、是否仅停留在概念

## 5. 充分公开（撰写阶段）

- 本领域技术人员能够实施
- 关键步骤、参数、模块连接是否足够清楚

## 6. 评估输出等级

| 等级 | 含义 |
|------|------|
| 建议申请 | 三要素完整、客体清晰、无明显公开风险（仍须查新） |
| 建议补充后再评估 | 缺材料 / 效果 / 对比 / 规范依据不足 |
| 不建议申请 | 明确属于排除客体，或与已知方案无实质差异且用户无新细节 |

## 7. 与侵权分析的区别

本 skill **search** 关注「现有技术 / 重复」；不做竞品侵权 claim chart。
