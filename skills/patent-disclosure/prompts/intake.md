# 边界与输入确认

## 用途

在不确定用户意图或缺少关键边界时，用**少量问题**收敛任务。信息不全时可跳过，由 Agent 推断并**注明假设**。

## 开场

```
为便于专利审核/转换/交底书撰写，先确认几项边界；可跳过，将按已有材料推断。
```

## 问题序列

### Q1：任务类型

```
您希望我做什么？
A. 评估创意/方案是否适合申请发明专利
B. 把论文或技术说明转成专利交底书
C. 修改/补充已有交底书
D. 查新与现有技术对比
E. 输出 Word/A4 或完整申请书
（可多选或用自己的话描述）
```

### Q2：技术主题

```
请用一句话描述技术主题，例如「多模态检索排序」「工业缺陷分级检测」。
```

### Q3：输入材料

```
请提供：论文/技术说明/交底书路径或粘贴正文；若仅有创意描述也可。
```

### Q4：模板

```
是否有机构交底书模板或参考格式？有则提供；无则是否同意使用内置通用模板？
```

### Q5：专利类型倾向

```
权利要求倾向：方法 / 系统 / 装置 / 暂不确定
```

## 汇总

将已确认项用 3–6 行 bullet 复述，再路由到对应 `prompts/*.md` 模式。
