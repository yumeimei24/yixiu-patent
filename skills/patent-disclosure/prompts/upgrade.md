# 完整发明专利申请书（upgrade）

## 前置

- 已有定稿交底书或等效完整技术素材
1. **`Read`** `references/regulatory-standards.md` 第三节（申请书约束）
2. **`Read`** `prompts/standards_lookup.md` 并 **WebSearch**「权利要求书 撰写规范 专利审查指南」
3. **`Read`** `references/claims-rules.md`
4. **`Read`** `references/patent-law-basics.md`

## 目标

在交底书基础上生成 **中国发明专利申请文件五大部分**（文本）：

1. 说明书摘要（≤300 字）
2. 摘要附图说明
3. 权利要求书（建议 ≤10 项）
4. 说明书（技术领域、背景、发明内容、附图说明、具体实施方式）
5. 说明书附图说明（文字描述；黑白线条框图/流程图规范）

## 转换原则

- **忠实交底书/源材料**：不添加未支持的特征、数据、硬件、场景
- 三要素闭环必须在权利要求与发明内容中体现
- 权利要求：**禁词**（等、大约、优选、可以、比如、不限于…）、**仅末尾一个句号**
- 从权引用基础必须成立
- 具体实施方式：步骤化专利语言，非论文腔；每关键步骤说明是什么、解决什么、如何操作、达到什么效果

## 输出

### 文本模式

按五大部分顺序输出完整中文专利文本。

### 文件模式（用户要求 DOCX 时）

1. 将五部分写入 `{案件名}_申请书_{YYYYMMDDHHmmss}.md`
2. 调用 `scripts/render_disclosure_docx.py` 生成 DOCX
3. 附图：文字描述 + 建议选取哪幅为摘要附图；若需 SVG/PNG 附图生成，说明需额外工具链

## 内部质检

**Read** `references/disclosure-checklist.md` 中申请书相关项，后台修订后再交付。

## 交付

- 文件路径
- 材料缺口与 `【待补充】` 列表（若有）
- **固定免责声明**

## 与交底书的区别

| 交底书 | 申请书 |
|--------|--------|
| 内部沟通、偏实施细节 | 法律文本、权利要求保护范围 |
| 可含联系人、注意事项 | 五部分法定结构 |
| 查新 URL 在 1.1 | 背景技术详述 + 权利要求布局 |

用户若仅需交底书，**不要**主动生成完整申请书。
