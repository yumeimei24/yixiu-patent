# 联网规范查询（standards_lookup）

## 目的

本 skill 的创意审核与文本撰写须**以现行专利法律与审查规范为硬约束**。除阅读 `${SKILL_DIR}/references/regulatory-standards.md` 外，在下列节点须 **WebSearch** 补充/核验最新要求，并将检索结论用于后续输出。

**原则**：规范冲突时，**官方法律与国知局公开文件**优先于行业文章；检索不到权威来源时，标注「规范依据不足」并保守处理。

---

## 必查节点

| 模式 | 何时联网 | 最低检索动作 |
|------|----------|--------------|
| **review** | 开始评估前 | 查「专利法 第二十五条 + 用户技术领域」；软件/AI 类另查「专利审查指南 计算机程序」 |
| **convert** | 材料涉及算法、商业方法、医疗、生物时 | 查对应领域审查指南章节 |
| **draft** | 首次撰写交底书前 | 查「技术交底书 撰写规范」+「国知局 专利申请文件 撰写要求」 |
| **upgrade** | 生成权利要求/说明书前 | 查「权利要求书 撰写规范 专利审查指南」+「T/CIPSA 0007 权利要求」 |
| **search** | 查新结论涉及创造性初判时 | 可选查「创造性 三步法 专利审查指南」 |

**不必每次全查**：若本会话内同领域已检索且用户未跨领域，可引用会话内已有检索摘要。

## 推荐检索 query 模板

### 可专利性 / 创意审核

```
专利法 第二十二条 新颖性 创造性 实用性 site:cnipa.gov.cn OR site:gov.cn
专利法 第二十五条 不授予专利权 [技术领域关键词]
专利审查指南 涉及计算机程序 发明专利 [若含软件/AI]
```

### 交底书撰写

```
技术交底书 撰写 背景技术 发明内容 实施例
国知局 规范 专利申请文件 撰写要求 2024 OR 2025
专利审查指南 说明书 撰写方式和顺序
```

### 权利要求 / 申请书

```
专利审查指南  makes 权利要求书 清楚 简要
权利要求 禁止 约 等 优选 其特征在于
专利申请文本撰写规范 T/CIPSA 0007 权利要求
```

### 领域专项（按需）

| 领域 | 追加 query |
|------|------------|
| 软件/AI | `专利审查指南 计算机程序 技术特征 算法` |
| 医疗 | `专利法 第二十五条 诊断治疗方法` |
| 生物 | `专利审查指南 生物材料 序列表` |
| 商业方法 | `智力活动规则 商业方法 技术特征` |

## 检索结果处理

1. **记录**：内部笔记含来源标题、URL、与本案相关的 1–3 条硬性约束
2. **映射**：将约束写入当前任务检查项（review 报告 / 交底书 / 权利要求）
3. **冲突**：官方法 > 团体标准 > 自媒体；无法确认时不放宽撰写红线
4. **交付**：review/upgrade 可在报告末尾附「规范依据摘要」（URL 列表）；交底书正文不写 URL

## 权威来源优先级

1. [国家知识产权局](https://www.cnipa.gov.cn/) 法律、审查指南、业务通知
2. 《中华人民共和国专利法》（2020 修正）及实施细则
3. 《专利审查指南》（2023 修订及后续公开版本）
4. 团体标准如 T/CIPSA 0007-2024《专利申请文本撰写规范》（与审查指南不一致时以审查指南为准）
5. 专利审查指南公开转载（看云、专业站点）— 仅作辅助查阅

---

## 禁止

- 未检索、未读 bundled 规范即输出「符合专利法」等结论
- 将自媒体观点当作法定要求
- 用检索结果编造不存在的法条或审查标准
